    常见问题排查

    10 类高频问题 + 自助排查步骤，按症状对号入座。

    1机器人不响应消息

    • 检查后台「机器人 → 机器人管理」：机器人是否处于「运行中」状态
    • 检查功能开关：对应功能开关是否关闭（默认全开）
    • 查看日志中心：搜索 ERROR，看是否有 SDK 鉴权失败

    2消息响应慢 / 卡顿

    • 打开「仪表盘」看 CPU / 内存 / 活跃会话
    • 活跃会话 > 100 通常是 5 子棋 / 成语接龙没释放
    • 可在「实时监控」页强制结束会话
    • 看一下「内存管理」页的「每日日志」是否 > 100MB（太久没清理会拖慢 IO）

    3后台打不开 / 9988 端口无响应

    排查步骤：
    # 1. 看 bot 进程是否在 netstat -ano | grep ":9988" # 2. 看 botpy.log 末尾 20 行 tail -20 botpy.log # 3. 看 stdout 日志 tail -20 bot_stdout.log 2>/dev/null # 4. 启动报端口占用 # 拿 PID 强杀后重启： Stop-Process -Id <PID> -Force Start-Process python -ArgumentList "bot.py" -WindowStyle Hidden

    4小说模块报错 / 渲染失败

    • 症状：用户点「看 三国演义」后报错或图片发不出去
    • 排查：日志搜 render_novel；看是否 Pillow 未安装
    • 修复：用 system Python 3.11 启动（3.13 没装 PIL），或者 pip install Pillow 到 3.13 venv
    • 注意：修改 data/render_novel.py 后必须重启 bot

    5AI 对话超时 / 不回复

    • 检查：模型管理页 API Key 是否有效（余额 / 过期）
    • 检查：敏感词是否开启（开启后部分回答会被过滤）
    • 检查：「AI 智能」总开关是否关闭（默认开）
    • 降级：在「AI 智能」页可设置主备模型（主模型失败时自动切到备）

    6QQ 端「重启」指令无效

    • 确认自己已在「管理员设置」列表内
    • 指令需是「重启」字面（/重启 不支持）
    • 需私聊机器人，群里说「重启」会被群管/功能开关拦截
    • 管理员名单会缓存 1 分钟（mtime 检测），保存后等 1 分钟再发

    7数据被误删 / 找不到历史消息

    • 消息记录：默认保留 7 天，可在 console_server.py 调整
    • 签到数据：SQLite data/checkin.db，删掉即丢失所有积分
    • 小说数据：data/classic_novels.json，手动备份即可
    • 恢复：所有路径都在「数据中心」页能跳到对应文件
    ⚠️ 重要 缓存清理（§13 功能）只清理白名单内 8 类文件，**绝不可能误删任何数据 / 配置 JSON**。

    8前端改了没生效

    • CSS / HTML 改动：浏览器硬刷新 Ctrl + F5（admin/index.html 自身无缓存戳）
    • JS 改动：缓存戳会每天自动 bump（?v=YYYYMMDDXX）；改动后会看到 charts.js?v=20260808v2 之类的新版本号
    • 后端 / render_novel 改动：必须重启 bot

    9bot 反复掉线 / WebSocket 断开

    • 通常原因：网络环境拦截了 wss://api.sgroup.qq.com
    • 尝试：换 4G / WiFi / 关闭代理
    • 查看日志：搜 WebSocket / ConnectionClosed

    10仍然无法解决

    1. 查看 botpy.log + bot_stdout.log 完整日志
    2. 看「日志中心」页筛 ERROR
    3. 导出 data/feature_config.json + 最近的相关日志
    4. 通过「问题反馈」页提交（GitHub / 邮箱 / 微信群）
